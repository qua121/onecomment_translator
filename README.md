# コメント翻訳プラグイン for わんコメ

日本語以外のコメント（英語・中国語・韓国語・スペイン語など）をリアルタイムで日本語に翻訳して別タブに表示するわんコメ用プラグインです。

## 動作環境

- わんコメ v5.2 以上
- 翻訳エンジン（いずれか）:
  - **DeepL**（推奨）: インターネット接続 + DeepL アカウント（無料）
  - **Google翻訳**: インターネット接続 + Google Cloud アカウント
  - **Ollama**: NVIDIA GPU推奨（VRAM 6GB以上）、インターネット不要

## 導入手順

### 1. DeepL APIキーを取得する

1. [DeepL公式サイト](https://www.deepl.com/account/summary) でアカウントを作成
2. 「DeepL API Free」プランを選択（月50万文字まで無料）
3. ダッシュボードからAPIキーをコピーする

### 2. プラグインをインストールする

1. [Releases](../../releases) から最新の `comment-translator-vX.X.X.zip` をダウンロード
2. ZIPを展開する
3. わんコメ右上メニュー → **プラグイン** → **プラグインフォルダ** を開く
4. 展開した `comment-translator` フォルダをプラグインフォルダ内に配置する
5. わんコメのプラグインウィンドウで **再読み込み** → プラグインを **有効化**

### 3. 翻訳エンジンを設定する

プラグインUIには以下のいずれかの方法でアクセスできます：

**方法A（推奨）**: わんコメのプラグイン管理パネルから、このプラグインの **設定ボタン** をクリック

**方法B**: ブラウザで直接URLを開く（わんコメ起動中）
   ```
   http://localhost:11180/plugins/com.qua121.comment-translator/index.html
   ```

#### DeepL を使う場合

1. **設定** タブを開く
2. 翻訳エンジンを **DeepL** に選択
3. DeepL APIキーを入力して **保存**

#### Google翻訳 を使う場合

1. [Google Cloud Console](https://console.cloud.google.com/apis/library/translate.googleapis.com) で **Cloud Translation API** を有効化
2. APIキーを発行する（認証情報 → APIキーを作成）
3. **設定** タブで翻訳エンジンを **Google翻訳** に選択
4. Google Cloud APIキーを入力して **保存**

#### Ollama（ローカルLLM）を使う場合

1. プラグインUIの **Ollamaガイド** タブに沿ってセットアップ
2. **設定** タブで翻訳エンジンを **ローカル / Ollama** に変更して **保存**

### 4. OBSに表示する（未検証のため非推奨）

翻訳結果をOBSのシーンに重ねて表示できます：

1. OBS → ブラウザソース追加
2. URLに以下を入力：
   ```
   http://localhost:11180/plugins/com.qua121.comment-translator/index.html
   ```
3. 幅・高さを任意に設定（推奨：幅 400px 以上）

## プラグインUIについて

このプラグインのUIは `http://localhost:11180/plugins/com.qua121.comment-translator/index.html` として独立したWebページで動作します。わんコメ本体のウィンドウ内に統合されるものではありません。

| 用途 | 方法 |
|------|------|
| 設定・翻訳履歴確認 | わんコメ プラグイン管理の設定ボタン、またはブラウザで直接URLを開く |
| 配信画面への表示 | OBSのブラウザソースとして追加（上記URLを使用） |

## 注意事項

### データの外部送信について

選択した翻訳エンジンに応じて、**コメントのテキストが外部サーバーに送信されます**。

| エンジン | 送信先 | 備考 |
|----------|--------|------|
| DeepL | DeepL社サーバー | Free APIはサービス改善に使用される場合あり |
| Google翻訳 | Google社サーバー | [Google Cloud プライバシーポリシー](https://cloud.google.com/terms/cloud-privacy-notice) 参照 |
| Ollama | ローカルのみ | 外部送信なし |

ユーザー自身がAPIキーを発行・設定することで、各サービスへの送信に同意したものとみなします。

### 文字数制限について

DeepL Free APIは月50万文字まで無料です。通常の配信コメント量では超過しませんが、超過した場合はエラータブに通知が表示されます。

Google Cloud Translation API は一定量（月500,000文字）の無料枠があります。超過後は従量課金となります。詳細は [Google Cloud 料金ページ](https://cloud.google.com/translate/pricing) を確認してください。
